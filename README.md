#  Bot Battlr

Welcome to **Bot Battlr** – a React-based app where you can collect bots, build your personal bot army, and remove unwanted bots.

##  Features

- Fetches a list of bots from a backend server.
- Click on a bot to add it to your army.
- Click again to remove it from the army.
- Use the ✖️ icon to permanently delete a bot from both the collection and your army.

## Tech Stack

- React
- JavaScript (ES6)
- CSS (Flexbox)
- Fetch API
